# CitizenServicesPlatform - Digital Government Services Platform

## Graduation Project

GovSphere is a full-stack digital government services platform developed as our Graduation Project. The system aims to simplify and digitize government services by allowing citizens to access services online, submit requests, upload required documents, complete payments securely, and track their applications digitally.

The platform also provides an administrative dashboard for reviewing applications, managing requests, and approving or rejecting submitted services.

## Features

- User Authentication & Authorization
- Browse Government Services
- View Required Documents
- Submit Service Requests
- Upload Documents
- Online Payment Integration
- Application Tracking System
- Admin Dashboard
- Request Approval Workflow
- Notifications & Status Updates

## Tech Stack

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication

## Project Goal

The main goal of this project is to support digital transformation by providing citizens with an efficient, secure, and user-friendly platform for accessing government services online.
